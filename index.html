A FEW MORE THINGS

Good questions.

Does this replace my coding agent?+

No. You keep working in Codex, Pi, OpenCode, or DeepSeek. Bridge supplies delegation rules and the connection to other harnesses. It’s a companion desktop app, not another coding chat.

Do I need another model subscription?+

Bridge doesn’t provide model access. Workers use their harness’s existing accounts, API keys, or configured providers. Whether a task consumes a subscription allowance or API credits depends on that setup.

Does everything stay on my computer?+

Bridge’s configuration and coordination run locally, without a hosted Bridge account. Your coding harnesses still send prompts and code to their configured model providers, just as they normally do. This website has no analytics or tracking cookies.

Will results arrive in my current chat?+

Supported parent integrations deliver background results to the originating session. Codex desktop hooks deliver during active turns or when a turn stops; an idle chat receives pending results on its next turn. Initial integration setup can require a reload, restart, or hook review.

What if I select several models or agents?+

They’re alternatives. The parent selects one worker and one model for each task, rather than starting all of them. Thinking settings belong to individual models and only expose the levels the harness supports.

Which platforms and agents are supported?+

The current desktop build has been tested on macOS Apple Silicon with Codex, Pi, OpenCode, and the desktop-bundled DeepSeek harness. Windows and Linux packaging is configured, but those native builds aren’t verified yet. Claude Code integration is deferred. Updates can affect compatibility; Settings reports the installed versions and connection state.
